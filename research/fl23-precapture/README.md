## 这次修改解决什么问题

此前的实机记录来自 11 月 15 日版本。在 JPEG 和 FL2／FL3 下，一次半按松开后再次按下，机身出现花屏，需要取出电池恢复。这个现象不能单独确定是滤镜参数、预拍摄收尾还是两者的时序导致。

此候选针对一个已找到的地址重叠问题。它把预拍摄的工作状态移出新版 FL2／FL3 使用的区域，让帧处理、结束通知、接收端和快速取消从同一处读写状态。初始化例程在设置默认值之后才标记状态可用。候选保留最长 800 ms 的预拍摄窗口。

## 目录内容

| 文件 | 用途 |
| --- | --- |
| `cp_bridge.S` | 管理预拍摄会话、窗口和结束处理 |
| `cp_vdf_token.S` | 跟踪连续拍摄中的帧完成通知 |
| `cp_receiver_pair.S` | 配对接收端的拍摄状态和结束事件 |
| `cp_fastoff.S` | 在快速取消时确认当前会话状态 |
| `cp_context_boot.S` | 初始化迁移后的预拍摄状态 |
| [validation.json](validation.json) | 记录五份源码的 SHA-256、参考版本和离线检查结果 |

## 验证到哪一步

已核对五份源码的摘要和已有离线测试记录。检查覆盖初始化、普通色彩与 FL2／FL3 的参数切换、帧完成与结束通知的顺序，以及快速取消的 19 个用例。这些结果限于记录中覆盖的输入和事件顺序。

新版 FL2／FL3 的色彩参数、机身相关设置和整机处理链仍需联调。尤其需要确认 JPEG 下“松开后立即第二次半按”时，机身显示、取消和最终保存均正常。目前不能据此判定实机花屏已修复。仓库根目录的 v0.3.0 打包说明用于历史版本，不能据此生成或安装本候选。

FL2／FL3 的色彩行为参考 QAQLeonard 的 a7c2-tools。参考版本见核验记录。[参考项目](https://github.com/QAQLeonard/a7c2-tools)
