# 研究状态与已知问题

**高风险，仅供研究学习。项目可能存在问题，不能作为稳定固件使用。**

本版发布的是截至 2026-11-11 的 800ms 研究补丁源码，并未宣称已修复全部相机故障。

- 用户报告新研究版半按取消与回放正常。
- 用户曾报告半按期间切换屏幕／取景器会卡死，需要拔电池恢复。随后用户无法复现，并说明可能由其他原因造成。因此，**卡死报告保留，触发条件和根因均未确认**；不能写成“眼部感应必然导致死机”，也不能因为无法复现就认定修复。
- “限制自动切换”方案已被撤销，从未实现；此发布版没有加入该限制。
- 过去实验版发生过黑屏、花屏、无响应及暂时无法检视存储卡照片等问题。当前补丁没有覆盖全部组合、机身与长时间压力测试。
- 自定义秒数菜单尚未实现。本版固定800ms；实际全按前的时间覆盖仍需要带时间标记的实拍验证，张数不能替代时间测量。
- 官方2.01输入生成的“仅预拍摄”组合仅经过完整离线校验，没有在相机上安装验证。已有研究基线生成的包可精确复现测试过的实验身份，但也没有通过整体稳定性验收。
- 对焦速度／频率、RAW、其他连拍档、视频、播放／模式切换、AF按钮触发、自动限制变化和不同卡／镜头组合没有完整验证。

## 离线证据的边界

新标记代码避免旧帧晚期重复改变 VDF 显示状态；原生句柄池复用、ABI、队列取消／提交与若干显示交错进行了指令级检查。模拟的硬件调用和线程调度不证明真实图像处理可靠。

后续切屏审计找到两路输出完成等待、引用归零通知及当前显示域状态条件，但未证明它们造成观察到的卡死。AP 的“空闲”状态也尚不能等同于成像处理器缓存排空。
