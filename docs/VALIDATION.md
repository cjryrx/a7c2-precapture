# 发布验证：v0.3.0-research

验证记录日期：2026-11-15。**仅供研究学习；离线校验及指定实测通过，不是长期稳定性认证或安装保证。** 固件、设备备份和原始工作文件均在公开发布目录之外。

## 本版研究组合的机身反馈

使用者对以下分组测试均反馈正常；未提供量化耐久次数。

| 分组 | 操作与观察 | 反馈范围 |
| --- | --- | --- |
| 预拍偏好OFF | 照片→视频→S&Q→照片，不按拍摄键 | 模式切换正常 |
| 预拍偏好ON | 同样切换照片→视频→S&Q→照片 | 模式切换正常 |
| 视频／S&Q启动 | 保留预拍偏好ON，分别在视频和S&Q档冷启动，短录制并回放 | 指定启动、录制、回放正常 |
| 仅JPEG照片 | 电子快门、Hi+；AF-ON仅对焦；半按约1秒后松开取消；半按约1秒后全按保存；更换景物再半按取消；关闭菜单后回放 | 取消不保存、全按保存、后续取消、红灯及回放正常 |
| 仅未压缩RAW照片 | JPEG正常后切换仅未压缩RAW，重复半按取消／全按保存／另一景物再次取消并回放 | 指定取消、保存、红灯及回放正常 |

这些是当前研究组合的测试。**官方输入配置没有在机身安装测试。** 不将短录制扩展为所有视频格式／长录制通过，也不将本轮正常反馈扩展为全部历史故障已消除。

## 安装后身份核对的含义

研究过程核对了CP／AP文件完整摘要、AP文件和闪存中选定映射块、运行中的AP补丁入口与菜单相关代码、菜单参数及正常USB状态，并完成临时门控恢复。

启动分区严格摘要检查曾因四个FAT时间字节变化而失败；原失败记录保留。独立核对完整本地分区参照与机内完整摘要，确认仅时间字段差异。一次运行态读取超时也保留记录，完整重启后另行补验成功。这些内部证据不随源码公开，不应被描述为所有检查一次通过。

CP文件摘要不等于CP运行内存身份。本轮未另行读取完整CP RAM，也没有以身份校验替代上述实际操作测试。
